# Royal Flight Club Party Menu Planner
App Created By: Micha Christine Dotimas

Static installable app for GitHub Pages. Publish from main branch, root folder.
Repository: royalflightclub/rfcpartymenu
Website: https://royalflightclub.github.io/rfcpartymenu/

## Updated 2026 catalogue
Includes 195 menu options from the revised party menu, with exact names, prices, sales units and subcourses. Each platter size remains a separate product. Starters and snacks appear first; desserts and drinks appear last.

Existing devices update unchanged original catalogue entries automatically. Locally edited entries remain intact and show a choice to apply the new workbook values. Custom products are kept. Items removed from the updated menu become inactive when unchanged locally. Draft lines and saved orders retain their copied prices, quantities and units. A previous catalogue snapshot is retained in full backups.

## Customer records
No customer records, saved orders, backups, or practice data are included in this repository.
Orders, catalogue edits and drafts are stored only in localStorage on each device/browser.
The app has no submission endpoint, analytics or cloud database. Public visitors cannot fetch another device's orders from GitHub.
Anyone using the same unlocked browser profile can access its local records. Backups and printed PDFs must be stored appropriately.
Moving from the previous domain does not migrate records automatically.

## Installation and printing
Open in Chrome or Edge, choose Install app. A4 portrait; browser Headers and footers off.
Creator attribution appears in the app only, not on printed order forms or page footers.
Search indexing is discouraged via robots.txt and noindex; the site is still public.

## Editing and deleting
Saved orders have Edit order and Delete order controls. Edits retain the order ID and store the earlier version in the full backup. Catalogue products have Edit and Delete controls. Deleted products can be restored from Deleted catalogue items; deleted orders can be restored from Recently deleted. Existing order lines retain their copied product details when a catalogue product is changed or deleted.
