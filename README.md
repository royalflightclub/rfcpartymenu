# Royal Flight Club Party Menu Planner
App Created By: Micha Christine Dotimas

Static installable app for GitHub Pages. Publish from main branch, root folder.
Suggested repository: royalflightclub.github.io (website at https://royalflightclub.github.io/).

## Customer records
No customer records, saved orders, backups, or practice data are included in this repository.
Orders, catalogue edits and drafts are stored only in localStorage on each device/browser.
The app has no submission endpoint, analytics or cloud database. Public visitors cannot fetch another device's orders from GitHub.
Anyone using the same unlocked browser profile can access its local records. Backups and printed PDFs must be stored appropriately.
Moving from the previous domain does not migrate records automatically.

## Installation and printing
Open in Chrome or Edge, choose Install app. A4 portrait; browser Headers and footers off.
Search indexing is discouraged via robots.txt and noindex; the site is still public.
