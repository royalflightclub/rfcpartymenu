Install Royal Flight Club · Party Menu Planner

Install on Windows using Microsoft Edge or Google Chrome.

On your computer

  1. Open the app link in Microsoft Edge or Google Chrome.
  2. Click Install app here, or the install icon in the browser address bar. Confirm Install.
  3. Launch Royal Flight Club · Party Menu Planner from the Start menu. You can pin it to your taskbar.

In Edge you can also open the ⋯ menu → More tools → Apps → Install this site as an app.

Install on an Android phone
  1. Open the app in Chrome.
  2. Tap Install app and confirm Install.
  3. Launch it from your phone’s apps screen.

Your installed app opens in its own window. If installation is unavailable here, use the app link in Edge or Chrome.
